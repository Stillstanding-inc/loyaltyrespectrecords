# Loyalty Respect Records

**Thank God first.**

Loyalty Respect Records is the record label of **James Albert Bosarge Jr.** —
founder of Still Standing Enterprises Productions and Products, Irvington, Alabama.
Southern gospel rap and country-gospel, written from a real life: prison, loss,
a mother's prayers, and standing back up. Every release is written, produced,
tagged, and stamped in-house — loyalty and respect aren't the slogan, they're
the standard the work is held to.
